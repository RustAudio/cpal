# Directives for agents working on the cpal repository

 - Read CONTRIBUTING.md before you make any change.
 - Install the git hook(s) located in .githooks.
 - Always plan before making non-trivial changes.
 - Always run `cargo fmt --all` and `cargo check --workspace`
   after making changes.
 - Before considering non-trivial changes done, aways have
   reviews performed by fresh subagents. Check for code
   quality issues, overengineering / code duplication, and
   verbosity / violation of contributing guidelines
